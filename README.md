# Study Match 

Study Match es una plataforma diseñada para facilitar la creación de grupos de estudio y la gestión de proyectos académicos. Permite a los estudiantes conectar con compañeros y unirse a equipos de trabajo en diferentes materias.

## Enlace del Proyecto

- [https://studymatch-ecru-six.vercel.app](https://studymatch-ecru-six.vercel.app)

---

## Tecnologías Utilizadas

### Frontend
- **React (con Vite):** Interfaz de usuario rápida y modular.
- **React Router Dom:** Gestión de rutas.
- **Fetch API:** Consumo de servicios REST.
- **Despliegue:** Vercel.

### Backend
- **Java Spring Boot:** Lógica de negocio y creación de la API REST.
- **Spring Security & JWT:** Autenticación de usuarios y protección de rutas.
- **Hibernate / JPA:** Mapeo objeto-relacional.
- **Despliegue:** Render (mediante Dockerfile).

### Base de Datos
- **PostgreSQL:** Sistema de gestión de bases de datos relacional.
- **Neon Cloud:** Alojamiento de la base de datos en la nube.
